# C# exception templates for Visual Studio
These are prebuilt exception item templates to make writing custom C# exceptions less painful.

# Installation
Just go into the Templates folder, download the zip file for the exception template you'll want (you can also download all),
then go into your Documents folder and into the Visual Studio directory (e.g. `Visual Studio 18` for VS 2026), into the Templates folder,
then Item Templates, and drag and drop the zips there. And finally restart visual studio and you'll have working exception templates.
